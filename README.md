 Marketing Campaign Performance Analysis Dashboard

## Project Overview

The Marketing Campaign Performance Analysis Dashboard is a two-page Power BI dashboard designed to analyze marketing campaign performance across different cities, channels, and campaigns.

It provides an interactive view of key business metrics including Revenue, Budget, Conversions, and ROI.

## Tools & Technologies

- Power BI
- Data Visualization
- KPI Cards
- Bar Charts
- Interactive Slicers
- Data Analysis

## Dashboard Structure

### Page 1 — Marketing Campaign Performance Dashboard

This page provides an overall view of marketing performance.

#### Key KPIs

- Total Conversions
- Total Revenue
- Total Budget
- Average ROI

#### Visualizations

- Revenue by City
- Budget by Channel
- Revenue by Channel
- Conversions by Channel

#### Interactive Feature

- City slicer for filtering the dashboard by individual cities.

### Page 2 — Campaign Analysis

This page focuses on campaign-level performance.

#### Features

- Date range slicer
- ROI by Campaign
- Campaign performance table
- Revenue by Campaign
- Average ROI by Campaign

The date slicer allows campaign performance to be analyzed for a selected time period.

## Key Insights

The dashboard can be used to identify:

- Cities generating the highest revenue.
- Marketing channels receiving the highest budgets.
- Channels generating the highest revenue.
- Channels generating the most conversions.
- Campaigns with strong ROI performance.
- Campaign performance over a selected date range.

From the dashboard:

- Delhi generates the highest revenue among the displayed cities.
- Google has the highest budget and revenue among the channels.
- Facebook leads in conversions in the overall view.
- Campaign ROI varies across different campaigns.

## Project Objectives

1. Monitor overall marketing campaign performance.
2. Compare channels based on budget, revenue, and conversions.
3. Analyze revenue performance across cities.
4. Identify campaigns with strong ROI.
5. Provide an interactive dashboard for business analysis.
